❓ Guide d'utilisation — FONCTIOP@LE WEB V 5.0

🎯 À quoi sert cet outil ?

FONCTIOP@LE WEB est un outil numérique de cartographie des responsabilités fonctionnelles au sein d'une agence comptable d'EPLE, conformément à l'instruction codificatrice M9.6 Op@le (janvier 2026).

Il permet de formaliser, pour chaque opération comptable et budgétaire, qui fait quoi (action directe, délégation, suppléance) et d'identifier les ruptures de chaîne de séparation ordonnateur/comptable.

💡 Conseil de démarrage : Commencez par renseigner le nom de votre établissement et de l'Agent Comptable dans la barre d'outils, puis parcourez les opérations domaine par domaine.

📋 Lire le tableau

Chaque ligne représente une opération comptable ou budgétaire. La couleur de fond indique la sphère :

CouleurSignification
Sphère ordonnateur — colonnes en-tête vert
Sphère comptable — colonnes en-tête bleu

👤 En-têtes de colonnes

Chaque colonne correspond à un acteur. L'en-tête contient :

  • Le libellé de la fonction — modifiable avec le crayon ✏️ (ex. : "La fondée de pouvoir")
  • Un champ Nom prénom pour identifier la personne

Les boutons + Ord et + Cpt permettent d'ajouter une colonne libre dans chaque sphère. Chaque colonne ajoutée peut être supprimée avec le bouton ✕ dans son en-tête.

✏️ Renseigner les cases (fond jaune)

Cliquez sur une case jaune pour ouvrir le menu. Chaque case peut contenir plusieurs symboles simultanément :

SymboleValeurSignification
Action directe — fond jaune plein (+ D et/ou S affichés par-dessus si cumul)L'agent réalise lui-même l'opération
DDélégationOpération exercée par délégation formalisée
SSuppléanceRemplacement pour les opérations majeures
💡 Cumul : Quand action directe et D ou S sont combinés, le fond reste jaune plein et les lettres D/S s'affichent par-dessus. Sans action directe, le fond reste neutre.
💡 Cerclage manuel : Le menu propose 5 types de cerclage : rouge plein (rupture maj. avec émargement), rouge pointillé (sans émargement), noir plein (absence à corriger), gris pointillé (absence justifiée), violet (contrôle de supervision). Indépendant de l'état coché.
💡 Effacement : Le bouton "Tout effacer" vide la case et supprime le cerclage.

📝 Modifications récentes des opérations (V5.0)

  • Organisation : lignes ordonnateur ajoutées dans "Gestion des délégations" et "Archivage classement"
  • Dépenses : renommages domiciliations, prise en charge, paiement ; ajout "Règlement des Demandes de paiement"
  • Paies : "Approbation CA" → "Contrôle de la compétence/plafonds"
  • Encaissement chèques/espèces : toutes les lignes passées en sphère comptable
  • Régie d'avance : saisie décaissements → comptable, "Régularisation budgétaire", "Réapprovisionnement"
  • Régie de recettes : ajout "Dépôt des fonds à la Banque Postale"
  • Inventaire stocks : "Pointage" → "Contrôle" (4 occurrences)

🔗 Qu'est-ce qu'une rupture de chaîne ?

La séparation ordonnateur/comptable est un principe fondamental de la comptabilité publique. Une rupture de chaîne survient lorsqu'une même personne intervient dans la partie ordonnateur ET dans la partie comptable d'une même opération.

✏️ Marquer une rupture sur une opération

Survolez une ligne d'opération : des petits boutons colorés apparaissent à droite. Cliquez sur le bouton correspondant au type de rupture :

VisuelTypeDescription
Absence de rupture justifiée Pas de rupture de chaîne — situation régulière et documentée
Absence de rupture à corriger Absence de rupture à régulariser impérativement
Rupture majeure avec émargement formalisé Cerclé rouge épais — émargement formalisé en place
Rupture sans émargement formalisé Cerclé rouge pointillé — pas d'émargement formalisé
⚠️ Le marquage apparaît sous forme d'un badge coloré sur le bord gauche de la cellule opération. La couleur de sphère (vert/bleu) reste toujours visible.

🏫 Siège et établissements rattachés

L'outil gère jusqu'à 13 entités : le Siège de l'agence comptable et 12 établissements rattachés (ER). Chaque entité dispose de son propre tableau indépendant.

➕ Ajouter un établissement rattaché

Cliquez sur le bouton ＋ à droite de la barre d'onglets. Si le Siège contient déjà des données, une fenêtre vous propose :

  • Tableau vide : l'ER part d'une page blanche
  • Reprendre les ruptures du Siège : les marqueurs de rupture de chaîne du tableau du Siège sont copiés dans ce nouvel ER — les attributions de rôles (✓, D, S) restent toujours vierges, propres à chaque établissement

✏️ Personnaliser un établissement

Le cartouche de chaque onglet permet de renseigner :

  • Nom de l'établissement, N° UAI, Agence comptable/Groupement
  • Date de réalisation, noms de l'Agent Comptable, du Fondé de Pouvoir, du Secrétaire Général, du Chef d'Établissement
  • Présenté au Conseil d'Administration : champ date optionnel, activé/masqué par le bouton +/−
  • Les libellés de ces fonctions sont modifiables avec le crayon ✏️ pour adapter le genre ou l'intitulé (ex. "La fondée de pouvoir")
  • Dans le tableau, les noms de chaque colonne acteur sont aussi saisissables directement dans l'en-tête

🗑️ Supprimer un établissement rattaché

Le bouton Supprimer (rouge) dans la barre d'outils de l'ER déclenche une confirmation. Le Siège ne peut jamais être supprimé.

⚠️ La suppression d'un ER est définitive. Pensez à sauvegarder votre travail avant toute suppression.

📊 Page de statistiques consolidées

L'onglet 📊 Statistiques agrège les données de tous les établissements et présente :

  • Indicateurs clés : nombre d'établissements, d'opérations, d'actions directes, délégations, suppléances, ruptures à corriger
  • Tableau des ruptures par établissement : comparaison ligne à ligne des marqueurs pour chaque entité, avec ligne de total consolidé
  • Taux de renseignement par domaine : progression visuelle du remplissage pour chaque catégorie d'opérations (Organisation, Budget, Dépenses, etc.)
💡 Les statistiques se recalculent automatiquement à chaque ouverture de l'onglet — elles reflètent toujours l'état le plus récent de vos données.

💾 Sauvegarder votre travail

Cliquez sur 💾 Sauvegarder dans le bandeau en haut. Un fichier .json est téléchargé sur votre poste, nommé automatiquement :

Fonctiop@le-v5.0-JJ-MM-AAAA.json

Ce fichier contient l'intégralité de votre travail : tous les établissements, toutes les coches, tous les marqueurs de rupture, les noms et dates.

📂 Reprendre un travail sauvegardé

Cliquez sur 📂 Charger et sélectionnez un fichier .json précédemment exporté. Toutes vos données sont restaurées intégralement.

⚠️ Le chargement d'un fichier remplace toutes les données actuellement affichées. Sauvegardez d'abord si nécessaire.

🔄 Partager entre collègues

Le fichier .json peut être transmis par messagerie ou déposé sur un espace partagé. Votre collègue n'a qu'à le charger dans l'outil pour retrouver exactement le même état.

🖨️ Impression globale

Le bouton 🖨️ Imprimer imprime tous les établissements (Siège + tous les ER) en une seule fois, chacun commençant sur une nouvelle page. Le format est A4 paysage avec marges réduites.

⚠️ Si vous avez ajouté beaucoup de colonnes libres (au-delà de 20 colonnes au total), un avertissement s'affiche car le tableau risque de déborder en largeur. Réduisez le nombre de colonnes libres pour une impression optimale.

📊 Imprimer les statistiques

Depuis l'onglet 📊 Statistiques, un bouton Imprimer dédié permet d'exporter la page de synthèse consolidée.

💡 Export PDF : Dans la boîte de dialogue d'impression de votre navigateur, sélectionnez « Enregistrer au format PDF » comme imprimante pour obtenir un fichier PDF directement utilisable.
⚠️ Les boutons, menus et éléments d'interface sont automatiquement masqués à l'impression — seul le contenu utile apparaît sur la page imprimée.
