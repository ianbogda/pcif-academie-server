# PCIF Académie 0.32.2 — Rapport RGAA public et planification accessibilité

- Le rapport RGAA publié est désormais rendu côté serveur sur une URL publique stable `/accessibilite/rapports/:slug`, sans dépendre du rendu React de la SPA.
- La page Accessibilité et l’administration pointent vers cette URL.
- Le rapport public possède un rendu HTML autonome et une commande Imprimer / PDF.
- Le schéma pluriannuel couvre désormais 2026–2028 avec objectifs annuels.
- Le plan d’actions 2026 liste les actions à traiter par chantier.
